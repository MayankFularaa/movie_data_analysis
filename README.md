# 🎬 Hindi Movie Analysis & Recommendation System

A visually-rich, interactive desktop application that analyzes Hindi movies using data from the TMDB API. Built with `Tkinter`, `Matplotlib`, `Seaborn`, and `ttkbootstrap`, the app provides data-driven insights and content-based movie recommendations.

## 🖼️ Features

✅ Modern GUI with dark glassmorphism style using `ttkbootstrap`  
✅ Real-time data fetching from TMDB API  
✅ Content-based movie recommendation engine  
✅ Embedded matplotlib visualizations (styled for dark UI)  
✅ Filters: Language, Genre, Rating, Year, Popularity  
✅ Charts:
- Top Rated Movies
- Genre Distribution
- Language Distribution
- Rating Histogram
- Release Trend Over Years
- Ratings Over Time with Moving Average
- Popularity vs Rating vs Vote Count (Bubble Chart)
- Correlation Heatmap
